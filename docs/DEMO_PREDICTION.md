# 현재 적설 기반 필요 살포량 시연

`/?demo=1` 또는 `데모 데이터로 둘러보기`로 데모 기관을 연다. 기존 26개 구역·146개 작업·전년도 가상 기록은 보존하고 `살포량 예상 시연 기준 v5` 마커로 가상 기준 3개만 한 번 추가한다. 실제 기관에는 이 패널·가상 기준·자동 입력을 적용하지 않는다.

## 핵심 시연

홈의 `현재 적설 기반 필요 살포량 예상`에서 얕은/보통/많은 적설, 미측정, 기준 밖 상황을 선택한다. 면적·적설 깊이·노면 온도·눈 상태·사전 눈 제거를 직접 바꿀 수 있다.

시연 기준은 1cm 이하 15g/㎡, 3cm 이하 20g/㎡, 5cm 이하 25g/㎡이며, 노면 온도 -10~2℃·적설·일부 눈 제거 조건에서만 적용한다. 이는 검증된 과학적 권장량이 아니라 **UI/업무 흐름 시험용 가상 기준**이다. 적설 조건에 맞는 등록 기준을 고른 뒤 `면적 × g/㎡ ÷ 1,000`으로 총 필요 kg을 예상한다. 사진 AI나 미래 날씨·결빙 예측 모델은 없다.

예: 120㎡·2cm → 2.4kg, 120㎡·0.8cm → 1.8kg, 120㎡·4cm → 3kg. 면적·온도 미측정, 유효하지 않은 값, 적용 범위 밖, 적설 0cm/적설 상태 충돌은 양을 만들지 않고 추가 정보·보류를 표시한다. 보류 시 표시하는 기준은 확정 적용량이 아닌 검토 후보임을 표시한다.

`이 예상량으로 데모 작업 시작`을 누르면 구역·입력·기준·예상량 사본을 가진 새 데모 작업이 현장 확인 상태로 저장된다. 실제 사용량·작업 시각·선택 비용·후속 관찰은 시험용 기본값을 제공해 저장 버튼으로 끝까지 진행할 수 있다. 실제 사용량은 예상량과 독립 필드이며, 추가 살포도 합산된다. 기본 비용은 가상 목표 단가 750원/kg 가정으로 실제 비용 자료가 아니다. 시각은 관찰 → 작업 → 후속 확인 순서로 입력된다. 수정된 작업은 이력 상단에 먼저 보인다.

## 기관 보상 시연

데모 기관의 성장·보상 메뉴에서 원본을 바꾸지 않는 미리보기를 제공한다. `모든 후속 확인이 끝난 시즌 가정`은 시뮬레이션에서만 완료 상태를 가정한다. 1~4단계 버튼은 설정 경계보다 0.5%p 높은 절감 시나리오로 가상 사용량을 계산하여 단계·할인·자체 실천 배지 UI를 보여준다. 실제 기록 완료 처리, 평가 저장, 할인 적용, 청구나 공인 인증이 아니다. 실제 기관의 기존 보류·평가 로직은 그대로 유지한다.

## 검증

- 타입·린트·기존 도메인 테스트와 신규 예상량/보류/시각 순서 단위 테스트
- 실제 Next.js 배포 빌드
- `scripts/verify-demo-prediction.mjs`: 조건별 예상량, 면적 변경, 누락/범위 밖 보류, 예상량 사본 저장, 실제/추가 사용 분리, 후속 확인 완료, 최신 작업 조회, 1~4단계 보상 미리보기의 원본 무변경, 모바일 폭, 새로고침 보존

```sh
PLAYWRIGHT_MODULE=/tmp/ecosnow-browser/node_modules/playwright-core/index.mjs ADMIN_TEST_URL=http://127.0.0.1:5177/ node scripts/verify-demo-prediction.mjs
```

기록·사진은 기존 로컬 저장 방식이며, 실제 인증·서버 공유·실제 결제·AI·외부 제보 API는 이 작업에서 연결하지 않는다.
