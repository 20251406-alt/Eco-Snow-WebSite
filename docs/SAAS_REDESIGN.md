# EcoSnow 요금제·SaaS UI 변경

## 구현

기존 `ecosnow-admin-v1` localStorage와 `ecosnow-photos-v1` IndexedDB 구조를 유지했다. 기존 기록·사진·기관·구역·기준·상태 전환·데모 실적 제외 규칙을 변경하지 않았다. 저장 객체에 선택 항목 `subscriptions`와 `inquiries`만 기관 ID별로 추가한다. 이전 저장 자료는 그대로 읽는다.

- 메뉴 8개: 기존 7개 메뉴 + 요금제·구독. 현재 메뉴·플랜·기관을 헤더와 사이드바에서 확인한다.
- 디자인 토큰, 카드·폼·버튼·배지·반응형 테이블·키보드 포커스·모바일 드로어·축약 저장 안내를 적용했다. Noto Sans KR/Pretendard와 시스템 한국어 폰트 fallback 스택을 사용한다. 외부 폰트 다운로드에 의존하지 않는다. 설치된 아이콘 라이브러리가 없어 작은 SVG 아이콘 컴포넌트를 사용하며 새 의존성은 추가하지 않았다.
- 홈은 미완료·후속 확인 업무와 최근 작업, 기간별 실제 사용량, 비교자료 등록, 현재 플랜에 집중한다. 실제 자료가 없는 값은 자료 없음으로 표시한다.
- 현장 기록은 관찰 → 산정·보류 → 실제 작업 → 후속 확인의 4개 화면으로 구분한다. 숨긴 화면은 마운트를 유지해 저장 전 폼 값도 단계 이동 시 보존한다. 관찰 이동에 누락 검사를 적용하고 기존 작업 상태 전환 검사는 그대로 사용한다. 완료 단계·입력 단위·필수 여부·오류 연결·작업 요약을 표시한다. 좁은 모바일에서는 요약을 펼칠 수 있다.
- 작업 이력은 데스크톱 표 / 모바일 카드로 표시한다. 안내량·실제 사용량을 분리하고, 검색·20건 단위 페이지 이동·삭제 확인을 제공한다.
- 기관 설정은 7개 분류에서 필요한 폼을 보여준다. 분류 이동으로 폼을 다시 생성하지 않으므로 작성 내용이 유지된다. 기관 변경은 해당 기관의 폼을 연다.

## 요금안 (부가세 별도 가안)

| 플랜 | 연간 계약 시 월 환산 | 연간 계약 금액 |
|---|---:|---:|
| 학교·소규모 기관 | 100,000원 | 1,200,000원 |
| 아파트·민간기관 | 200,000원 | 2,400,000원 |
| 지자체 | 800,000원 | 9,600,000원 |

사업모델 검토용이며 실제 결제·계약·청구·자동갱신·환불을 구현하지 않았다. 실제 기능에 유료 접근 제한을 걸지 않는다. 관리 구역/계정/저장/지원 한도를 임의로 약속하지 않는다.

제품은 SW 요금과 별도로 목표 판매가 15,000원/20kg을 표시한다. 실제 견적·공급 조건은 별도 협의한다. 제품 인증·성능·납품 실적을 추가하지 않았다.

플랜 선택은 기관별 로컬 체험 상태이다. 제품 문의 작성이 임의로 플랜을 고르지 않는다. 지자체 도입 상담 초안 저장 버튼은 체험 선택만 저장하며 계약이 아니다. 문의는 작성·로컬 저장·복사만 지원하고 실제 전송은 하지 않는다. 클립보드 실패 시 수동 복사를 안내한다. 입력 초안의 자동 저장 실패도 사용자에게 표시한다.

실제 AI·결제·인증·서버 동기화·외부 제보는 미연결이다. 기관 간 보안 격리가 아닌 브라우저 내 구분이라는 기존 한계를 저장 안내에 명시한다.

## 검증

```sh
npm run typecheck
npm run lint
npm test
npx --no-install next build
```

`npm test`는 기존 테스트와 가격 계산/체험 플랜 테스트를 실행한다. 별도의 Chromium 검증(프로젝트 의존성 추가 없이 준비한 playwright-core 필요):

```sh
PLAYWRIGHT_MODULE=/tmp/ecosnow-browser/node_modules/playwright-core/index.mjs ADMIN_TEST_URL=http://127.0.0.1:5174/ node scripts/verify-admin-browser.mjs
PLAYWRIGHT_MODULE=/tmp/ecosnow-browser/node_modules/playwright-core/index.mjs ADMIN_TEST_URL=http://127.0.0.1:5174/ node scripts/verify-saas-browser.mjs
```

`verify-saas-browser.mjs`는 기관별 플랜 저장·새로고침·기존 작업 보존·문의 초안 재진입·설정 폼 유지·유료 차단 없음·누락 시 보류·모바일 드로어 키보드·360/390/768/1280/1440px의 홈/현장/이력/리포트/요금제 25개 화면을 검사한다. 캡처는 Git에서 제외한 `outputs/ui-review/`에 저장한다. 데스크톱·모바일 캡처를 직접 열어 시각적으로 점검한다. 실제 기기 테스트와 서버 접근 제어 감사는 수행하지 않는다.
